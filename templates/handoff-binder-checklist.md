# Handoff Binder Checklist

<!-- Print or copy into the binder. Build it all year; the year-end close
     (final chapter of the handbook) just tops it off. Masked means last-4
     digits only — full account numbers and passwords NEVER go in here. -->

# [Club Name] — Treasurer Handoff Binder — [Year]

## 0. Start Here (1 page, written for the successor by name)

- [ ] Congratulations + "here's the job in one page" (accounts, rhythm, keys)
- [ ] The five keys: bank, ledger, unreconciled paper, dues list, signatories
- [ ] One warm paragraph: *you've got this*
- [ ] Who to call: president [ ], bank rep [ ], venue manager [ ]

## 1. Accounts

- [ ] Operating: purpose, bank, **masked** number, signer list + date verified
- [ ] Reserve: same fields + what it's earmarked for
- [ ] Statement access: who has it, how (must be more than the treasurer)
- [ ] Card status: Operating card exists; Reserve card does NOT exist
- [ ] Monthly-fee details and minimum balances, if any

## 2. Ledger

- [ ] Full-year ledger copy/export attached (or its location + how to get it)
- [ ] Blank [starter template](ledger.csv) included for next year
- [ ] One paragraph: how I kept it, anything unusual I noted

## 3. Monthly reports (all twelve, unaltered, in order)

- [ ] January → December posted reports, plus the final December report

## 4. Receipts & reimbursements

- [ ] Year's receipts filed (or pointer to where they live + naming scheme)
- [ ] Blank [reimbursement form](reimbursement-request.md) in current use
- [ ] Lost-receipt notes, if any, filed with their approvals

## 5. Vendors

- [ ] [Vendor payment log](vendor-payment-log.csv) for the year
- [ ] Standing quotes/contracts + vendor contacts
- [ ] Two-quote rule threshold as the club set it

## 6. Dues

- [ ] Year-end [dues tracker](dues-tracker.md) (paid/unpaid per cycle per member)
- [ ] Dues amounts and cycle as set for next year
- [ ] The reminder rhythm used, so it can stay identical

## 7. Year-end money work

- [ ] December report posted; ledger reconciled through the last day
- [ ] Year-end bank statements for both accounts
- [ ] Unresolved items listed honestly, with what was done about each

## 8. Access changes for the OUTGOING treasurer (that's you)

- [ ] Bank signer removal completed (same week as handoff)
- [ ] Cards issued in your name: cancelled
- [ ] Logins you held: handed over; successor rotates passwords

## 9. Decrypt-your-successor's-week-one checklist (from Chapter 1)

- [ ] Request bank access; start signer-transfer paperwork in week one
- [ ] Count cash with a witness; both initials and date in the ledger
- [ ] Read the last three months of activity; ask about anything odd
- [ ] Copy the ledger template; write yourself the one-page "keys" note (masked)
- [ ] Announce the monthly report rhythm out loud — outsourced discipline

## Notes for my successor (free-form page)

- [Things the numbers don't say. The snack vendor who gives us a deal. The
  member who counts cash best. The thing you'd do differently. Warm is fine.]
